🍔 Food Order App (React) – Frontend Only

This is a simple beginner-friendly React project where users can view meals, add items to a cart, and submit an order using a basic form. The goal of this project was to practice React components, props, state management, context, modals, and form handling.

🚀 What I Learned in This Project

As a beginner, this project helped me understand:

How to create and structure React components

How to pass data using props

How to manage state with Context + Reducer

How to make simple GET and POST requests

How to build modals and overlays

How to use custom components (Button, Input, Modal)

Basic form validation

How to make a responsive UI

How to organize a React project cleanly

📌 Features (Frontend Only)

Display meals fetched from a backend (dummy data)

Add meals to the cart

Increase or decrease item quantities

Show cart modal with total amount

Simple order checkout form

Frontend validation

Loading & error feedback using a custom hook

Fully built with React functional components

🛠 Tech Used

React (Functional Components)

Context API

useReducer

CSS Modules

Custom Hooks

Fetch API (for GET and POST)

No backend. No database.
Just pure frontend practice for learning React.
